Protocol

The audio streaming protocol. Sendspin integrates natively with Music Assistant for synchronized multi-room audio. Snapcast (ESPHome) wraps CarlosDerSeher/snapclient with Home Assistant integration. Snapcast (standalone) runs CarlosDerSeher/snapclient bare on ESP-IDF with no ESPHome or HA integration.

Bluetooth

BLE is used for WiFi provisioning via Improv — configure WiFi credentials from a phone without USB. Disabling it frees ~100 KB of RAM and is recommended once the device is set up.

      Changes vs upstream snapclient
      
Based on CarlosDerSeher/snapclient with the following additions:

      
    
        
  • Exponential volume curve — maps the volume slider to perceived loudness using a dB-range exponential curve; range (0-90 dB, default 40 dB) is adjustable in the DSP settings page and persisted to NVS.
    • 
        
  • Channel routing — runtime Stereo / Left Only / Right Only / Mono mode in the general settings page, persisted to NVS. Enables two speakers to act as a stereo pair; Mono mixes L+R to both outputs.
    • 
        
  • WiFi TX power — slider in the general settings page (dBm), applied at boot and live on change, persisted to NVS. Useful for compact PCB antennas that self-interfere at high power.
    • 
        
  • Web OTA (push) — firmware updates over WiFi via a browser UI at /ota-update.html or POST /api/ota/upload. Displays current and pending firmware details (version, build date, SHA256) side-by-side before flashing. The OTA binary is also available for download above.
    • 
        
  • Web OTA (pull) — device fetches a manifest URL (POST /api/ota/pull), version-checks against running firmware, then downloads and flashes the listed binary with SHA-256 integrity verification. Pre-configured to pull from this page.
