Speakeasy

ESP32-S3 multi-room audio firmware. Plug in via USB and flash below. Requires Chrome or Edge, or Firefox with the WebSerial extension.

Protocol

The audio streaming protocol. Sendspin integrates natively with Music Assistant for synchronized multi-room audio. Snapcast is a generic audio client that can be driven by Music Assistant or any Snapcast-compatible source.

Snapcast Server

How the device locates the Snapcast server. Static IP requires the server address to be set in the config file before flashing. mDNS discovers it automatically on the local network.

Bluetooth

BLE is used for WiFi provisioning via Improv — configure WiFi credentials from a phone without USB. Disabling it frees ~100 KB of RAM and is recommended once the device is set up.

IPv6

Enable if your network uses IPv6 addressing or your Home Assistant instance is IPv6-only. Has no effect on IPv4-only networks.

WiFi TX Power

The compact PCB antenna can self-interfere at high TX power, causing Sendspin timing failures. 9 dBm is a safe fixed limit. Ramp variants expose a Home Assistant control and automatically step power up when WiFi drops.

Output

Single drives one I2S DAC. Dual simultaneously outputs to two separate I2S DACs wired to different GPIO pins.
