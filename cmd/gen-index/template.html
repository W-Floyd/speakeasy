Protocol

The audio streaming protocol. Sendspin integrates natively with Music Assistant for synchronized multi-room audio. Snapcast (ESPHome) wraps CarlosDerSeher/snapclient with Home Assistant integration. Snapcast (standalone) runs CarlosDerSeher/snapclient bare on ESP-IDF with no ESPHome or HA integration.

Bluetooth

BLE is used for WiFi provisioning via Improv — configure WiFi credentials from a phone without USB. Disabling it frees ~100 KB of RAM and is recommended once the device is set up.

Output

Single drives one I2S DAC. Dual simultaneously outputs to two separate I2S DACs wired to different GPIO pins.

Changes vs upstream snapclient

Based on CarlosDerSeher/snapclient with the following additions:

  • Exponential volume curve — maps the volume slider to perceived loudness using a dB-range exponential curve; range (0–90 dB, default 60 dB) is adjustable in the DSP settings page and persisted to NVS.
  • Channel routing — runtime Stereo / Left Only / Right Only mode in DSP settings, persisted to NVS. Enables two speakers to act as a stereo pair.
  • WiFi TX power — slider in the general settings page (8.5–20 dBm), applied at boot and live on change, persisted to NVS. Useful for compact PCB antennas that self-interfere at high power.
  • Web OTA — firmware updates over WiFi via a browser UI at /ota-update.html or POST /api/ota/upload. Displays current and pending firmware details (version, build date, SHA256) side-by-side before flashing. The OTA binary is also available for download above.
